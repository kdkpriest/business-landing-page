AWS Static Website Deployment

This project demonstrates how to deploy and host a static website on AWS. It covers cloud networking, server configuration, web hosting, security groups, and connecting a custom domain.

Amazon EC2Nginx web hostingVPC & security groupsRoute 53 domain

PROJECT OVERVIEW

A static site on AWS

The goal was to make a static website available from an AWS-hosted server and connect it to a custom domain. Amazon EC2 provides the host, while Nginx serves the website files. The project materials also identify a VPC, security groups, and Route 53.

This page describes the services recorded for the project without assuming specific instance settings, network routes, security-group rules, or domain record values that are not documented.

IMPLEMENTATION STEPS

The confirmed setup

  1. Deploy the static website on an Amazon EC2 host.
  2. Use Nginx to serve the website.
  3. Use the VPC and security groups for the AWS network and traffic-control layer.
  4. Connect a custom domain using Route 53.

The available project materials do not record the operating-system commands, DNS record values, or exact network and security-group configuration.

RESULTS & LESSONS LEARNED

A clear path to the site

The documented result is a static website hosted with EC2 and Nginx, using VPC networking, security groups, and Route 53 for a custom domain. No performance metrics are recorded, and this page does not claim that the AWS infrastructure is still running.

A general lesson from the setup is that a hosted site depends on several parts working together: the web server must serve the files, network rules must allow the required traffic, and DNS must direct the domain to the host.
