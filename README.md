# Nwafor Digital Landing Page

A responsive, service-based landing page built with plain HTML, CSS, and JavaScript.

## Files

- `index.html` — semantic page structure and content
- `style.css` — responsive styling for desktop, tablet, and mobile
- `script.js` — accessible mobile navigation and dynamic footer year
- `images/` — add your project screenshots and other image assets here

## Run locally

Open `index.html` in a browser, or serve this folder with any basic static file server. No build step or framework is required.

## Before publishing

Update the sample business name, `[Your Name]`, WhatsApp number (`2340000000000`), email address, and portfolio previews in `index.html`. Portfolio artwork is currently made with CSS; replace each project preview with an `<img>` element referencing a file in `images/` when you have project screenshots.
